# Gestión de Sprints e Iteraciones - PrettyCalc

Este directorio almacena la documentación específica de cada ciclo de desarrollo (Sprint).

## Estructura Recomendada de Carpetas

```text
Docs/Sprints/
├── README.md
├── sprint-template.md
├── Sprint-1/
│   ├── goals.md
│   ├── tasks.md
│   └── review.md
├── Sprint-2/
│   └── ...
```

## Flujo por Sprint

1. **Planificación:** Duplicar [sprint-template.md](file:///home/ro/Projects/PrettyCalc/Docs/Sprints/sprint-template.md) dentro de una carpeta específica `Sprint-N/`.
2. **Definición de Requerimientos:** Listar historias de usuario o requerimientos funcionales específicos de la iteración.
3. **Desarrollo:** Mantener actualizadas las tareas en progreso.
4. **Revisión y Retrospectiva:** Documentar entregables completados y lecciones aprendidas.
