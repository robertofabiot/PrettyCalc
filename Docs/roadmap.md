# Hoja de Ruta (Roadmap) - PrettyCalc

## 1. Visión del Producto
Desarrollar una aplicación de escritorio interactiva, elegante y en Python puro para la resolución y visualización paso a paso de problemas de álgebra lineal, construida de forma puramente iterativa e incremental.

## 2. Metodología de Desarrollo
El proyecto no asume un listado cerrado de funciones de antemano; en su lugar, evoluciona mediante **Sprints sucesivos** donde el usuario suministra e introduce progresivamente la documentación y requerimientos específicos de cada operación o componente.

```text
Iteración N:
Requerimientos de Usuario ──► Documentación en Docs/Sprints/Sprint-N/ ──► Implementación y Tests ──► Validación
```

## 3. Registro de Sprints
La planificación, especificaciones de operaciones y entregables de cada iteración residen en su carpeta correspondiente dentro de [`Docs/Sprints/`](file:///home/ro/Projects/PrettyCalc/Docs/Sprints/):

* [**`Docs/Sprints/Sprint1/`**](file:///home/ro/Projects/PrettyCalc/Docs/Sprints/Sprint1/): Solución de Sistemas Lineales por Eliminación por Filas (Completado · Programa 1).
* [**`Docs/Sprints/Sprint2/`**](file:///home/ro/Projects/PrettyCalc/Docs/Sprints/Sprint2/): Operaciones Algebraicas en $\mathbb{R}^n$, Combinación Lineal y Ecuaciones Matriciales (Planificado · Programa 3).
